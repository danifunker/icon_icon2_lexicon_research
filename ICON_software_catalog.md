# ICON Software Catalog

Every ICON / LEXICON title found so far in the book and the archived web sources, grouped by subject. A tracking copy with blank columns for your archive work (have media / imaged / image file / boots) is in [ICON_software_catalog.csv](ICON_software_catalog.csv).

**220 entries** (189 from the first pass + 31 from the York University material, 2026-10-28). Titles are spelled as they appear in the sources; obvious typos are noted. Where one listing has several spellings or variants, they're merged into one entry.

**Prefixes:**
- *Ambience*: the title ran under the Helicon/Unisys Ambience interface.
- *OESS*: likely the Ontario Educational Software Service, the Ministry's distribution channel. The 1991 ERIC report says 108 programs were available through it by 1987.
- *(re-release)*: a later revised edition.

**Source tags:** VCF = VCFed forum inventory (2019 lot), which is the backbone of this list · JF = Jacob Filipp · WP = Wikipedia · GB = Giant Bomb thread · PGC = Post Game Content · PR = Pop Rewind · PCM = pcmuseum.ca comments · OCS = old-computers.com user stories · OC = old-computers.com main page · DP = Doug Peterson · DY = Dean Yergens comments · JE = Jason Eckert · JD = Julian Dunn · AA = Anthony Anjo · YU = York University Computer Museum (1987 list) · W88 = Willing, *Journal of Reading*, 1988 · Book = *The Book of ICON*.

## Where to look for media

- **Archives of Ontario** hold ICON-era floppies. A collector reports recovering QNX 2, Turing, Pascal and C there (GB). Search terms: Ambience, Cemcorp, Unisys, Burroughs, Meridian (JF).
- **Private collectors:** System 3.00.00 and 4.00.00 disk images exist (DY). A Toronto collector has ROM dumps and a memory map (GB).
- **pcmuseum.ca** (Brantford, ON) has a working system and software (PCM, DY).
- **The VCFed 2019 lot** (Toronto) had most of the titles above on original disks; what happened to it is unknown (VCF).
- **A school-run public-domain library** of teacher-written ICON programs once existed, but its keeper says none of it survived (PR comments).
- **DOS or Apple versions** of some titles (Crosscountry Canada, Ernie's Big Splash, Lemonade Stand, Northwest Fur Trader) are on archive.org. They are useful for reference but are not the ICON builds.
